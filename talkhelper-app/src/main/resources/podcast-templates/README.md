# 播客脚本生成提示词模板库

本目录包含多种播客脚本生成模板，用于将文本内容转换为生动的双人对话播客。

---

## 模板索引

1. **template_standard.md** - 标准通用模板（5分钟）
2. **template_deep_dive.md** - 深度解析模板（10-15分钟）
3. **template_quick_tips.md** - 快速技巧模板（3分钟）
4. **template_storytelling.md** - 故事叙述模板（8分钟）
5. **template_debate.md** - 观点辩论模板（6分钟）
6. **tutorial_guide.md** - 使用指南

---

## 快速开始

### 基础用法

```markdown
请根据以下模板生成播客脚本：

【选择模板】template_standard.md
【输入文本】{你的文本内容}
【输出要求】严格按照模板格式输出
```

### 高级用法

```markdown
请根据以下参数生成播客脚本：

【模板】template_deep_dive.md
【输入文本】{你的文本内容}
【角色设定】主持人(科技博主) + 嘉宾(AI专家)
【时长要求】12分钟
【特殊要求】增加案例分析环节
```

## 通用标注规范

所有模板遵循统一的标注体系：

### 角色标注
- `[主持人]` - 节目主持人
- `[嘉宾]` - 受邀专家
- `[旁白]` - 叙述性内容（可选）

### 语气标注
- `(平静)` - 平和叙述
- `(兴奋)` - 热情高涨
- `(严肃)` - 认真郑重
- `(疑问)` - 提出疑问
- `(幽默)` - 轻松诙谐
- `(感慨)` - 感叹抒情

### 停顿标注
- `[停顿1秒]` - 短暂停顿
- `[停顿2秒]` - 中等停顿
- `[停顿3秒]` - 较长停顿（强调）

### 音效标注
- `[背景音乐：轻快钢琴曲]` - 背景音乐
- `[音效：翻书声]` - 环境音效
- `[音效：掌声]` - 特殊音效
- `[音乐渐弱]` - 音乐过渡

## 最佳实践

### ✅ 推荐做法

1. **选择合适的模板**
   - 简短资讯 → quick_tips
   - 技术教程 → standard
   - 深度分析 → deep_dive

2. **提供清晰的输入文本**
   - 结构化内容（标题、段落分明）
   - 核心知识点明确
   - 去除冗余信息

3. **指定角色背景**
   ```
   主持人：科技爱好者，善于提问
   嘉宾：AI研究员，专业严谨
   ```

4. **控制输出长度**
   - 5分钟 ≈ 800-1000字对话
   - 10分钟 ≈ 1600-2000字对话

### ❌ 避免做法

1. ❌ 输入文本过长且无结构
2. ❌ 不指定时长要求
3. ❌ 忽略语气和停顿标注
4. ❌ 添加与原文无关的内容

## 示例演示

### 输入
```
人工智能正在改变我们的工作方式。自动化技术可以处理重复性任务，
让人类专注于创造性工作。未来，人机协作将成为主流模式。
```

### 输出（使用template_standard.md）
```markdown
# 播客脚本：AI如何改变我们的工作

## 开场白
[背景音乐：轻快电子乐，音量20%]
[主持人]：(兴奋) 大家好，欢迎收听《科技前沿》，我是主持人小林！
[嘉宾]：(平静) 大家好，我是AI研究员张教授。
[主持人]：今天我们要聊的话题是——AI如何改变我们的工作！

## 核心内容
[主持人]：(疑问) 张教授，很多人担心AI会抢走我们的工作，您怎么看？
[嘉宾]：(严肃) 这是个常见误解。[停顿1秒] 实际上，AI更多是辅助而非替代。
[主持人]：能具体说说吗？
[嘉宾]：比如自动化技术可以处理重复性任务，[停顿1秒] 让人类专注于创造性工作。
[音效：键盘敲击声]
...

## 结束语
[背景音乐：渐弱]
[主持人]：感谢张教授的精彩分享！
[嘉宾]：谢谢大家，下期再见。
```

```markdown
...

...

## 结束语 (时长: XX秒)

[主持人]：总结...
[嘉宾]：告别...
```
