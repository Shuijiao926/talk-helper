# 播客脚本：{标题}

## 模板说明
- **适用场景**：观点讨论、争议话题、利弊分析、政策辩论
- **建议时长**：6分钟（约900-1100字对话）
- **角色设定**：主持人（中立调解者）+ 嘉宾A（正方）+ 嘉宾B（反方）
- **难度等级**：⭐⭐⭐

---

## 提示词模板

```
你是一位擅长引导辩论的播客制作人，能平衡呈现不同观点。

请将以下文本转换为时长约6分钟的观点辩论播客脚本，要求：

### 1. 角色设定
- **主持人**：中立客观、善于提问、控制节奏、总结共识
- **嘉宾A**：正方代表、逻辑清晰、数据支撑、坚定但不偏激
- **嘉宾B**：反方代表、视角独特、质疑精神、理性反驳

### 2. 结构要求
- **开场白**（30秒）：抛出争议话题、介绍双方立场
- **第一轮：立论**（2分钟）：双方各陈述核心观点（各1分钟）
- **第二轮：交锋**（2分钟）：互相质疑、回应反驳
- **第三轮：共识**（1分钟）：寻找共同点、妥协空间
- **结束语**（30秒）：总结要点、开放思考

### 3. 风格要求
- 保持理性和尊重，避免人身攻击
- 双方论点都要有说服力
- 主持人适时介入，防止跑题
- 允许观点碰撞，但控制情绪
- 最终要有建设性结论

### 4. 标注规范
- **角色**：[主持人]、[嘉宾A]、[嘉宾B]
- **语气**：(平静)、(坚定)、(疑问)、(反驳)、(思考)、(妥协)
- **停顿**：[停顿1秒]、[停顿2秒]
- **音效**：[背景音乐：中性钢琴曲]、[音效：提示音]（换轮次）

### 5. 内容要求
- ✅ 双方观点都要充分展开
- ✅ 每方至少提供2个论据
- ✅ 包含具体案例或数据
- ✅ 最终要有建设性总结
- ❌ 不偏向任何一方
- ❌ 不让一方压倒另一方

### 6. 输出格式

### 第一轮：立论
```

## 使用示例

### 输入文本
```
远程办公是否应该成为常态？支持者认为：提高员工满意度、降低办公成本、扩大人才池。
反对者认为：削弱团队凝聚力、沟通效率下降、工作生活界限模糊。
```

### 预期输出（节选）
```markdown
# 播客脚本：远程办公：未来趋势还是临时方案？

## 开场白
[背景音乐：轻快钢琴曲，音量20%]
[主持人]：(平静) 疫情后，远程办公该继续吗？今天我们请来HR总监李总和创业CEO王总。
[嘉宾A]：(平静) 大家好，我是李总，我支持远程办公常态化。
[嘉宾B]：(平静) 大家好，我是王总，我认为应该谨慎。

## 核心内容
### 第一轮：立论
[主持人]：(平静) 李总，请先说说您的观点。
[嘉宾A]：(坚定) 远程办公有三大优势。[停顿1秒] 第一，员工满意度提升40%；第二，公司节省30%办公成本；第三，可以招聘全球人才。
[音效：提示音]
[主持人]：(平静) 王总，您怎么看？
[嘉宾B]：(坚定) 我承认这些好处，但问题更严重。[停顿1秒] 团队凝聚力下降、新人培养困难、创新灵感减少。这些都是致命伤。

### 第二轮：交锋
[嘉宾A]：(反驳) 但数据表明，远程团队的生产力反而更高。
[嘉宾B]：(反驳) 短期是这样，长期呢？[停顿1秒] 我观察到，远程半年后，团队协作明显变差。
[主持人]：(疑问) 这个矛盾怎么解释？
[嘉宾A]：(思考) 可能需要更好的管理工具...
[嘉宾B]：(平静) 或者混合模式，每周2天办公室。

### 第三轮：共识
[主持人]：(思考) 听起来，两位都认同完全远程或完全坐班都有问题？
[嘉宾A]：(妥协) 是的，灵活性最重要。
[嘉宾B]：(妥协) 我同意。混合模式可能是最优解。
...

## 结束语
[背景音乐：渐弱]
[主持人]：(平静) 或许，没有标准答案，只有最适合的方案。感谢两位！
```

## 注意事项

1. **平衡原则**
   - 双方发言时间相当
   - 论据质量对等
   - 不让一方占上风

2. **主持技巧**
   - 及时打断冗长发言
   - 引导回到主题
   - 总结关键分歧点

3. **辩论礼仪**
   - 对事不对人
   - 用数据说话
   - 承认对方合理之处

4. **避免陷阱**
   - ❌ 不要变成吵架
   - ❌ 不要一边倒
   - ❌ 不要无结论

---

## 变体建议

### 多方辩论版（4人）
- 添加第4个角色（中立观察者）
- 增加投票环节
- 听众参与互动

### 快速辩论版（3分钟）
- 每轮压缩到30秒
- 只讲核心论点
- 去掉案例分析
